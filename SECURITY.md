# Security Policy

## Reporting a vulnerability

Please use GitHub's **Private vulnerability reporting** for this repository:
https://github.com/akazymova57-cmd/AI-Job-Finder/security/advisories/new

Do not publish exploit details, credentials, personal data, or proof-of-concept payloads in a public issue.

Reports should include:
- affected URL, file, or component;
- impact and realistic attack scenario;
- reproducible steps, avoiding destructive actions;
- suggested mitigation, if known.

Please allow reasonable time for investigation and remediation before public disclosure. This project is a small static website; response and remediation times are not guaranteed.

Preferred languages: Russian or English.
