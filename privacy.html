1. Оператор и область действия

Политика описывает обработку данных при использовании сайта AI Job Finder (далее — Сайт). Оператор должен обеспечить доступность актуальной версии Политики до начала соответствующей обработки.

2. Какие данные и для чего используются

  • Настройки интерфейса. Выбранный язык, избранные вакансии, локальный кэш списка вакансий и связанные с ним технические отметки могут храниться в localStorage браузера для работы функций Сайта.
  • Текст резюме. Введённый или загруженный файл TXT/MD используется в текущем сеансе браузера для локального выделения навыков и сравнения с вакансиями. Согласно текущей реализации, текст резюме не отправляется на сервер AI Job Finder и не сохраняется в localStorage. Не вводите специальные категории персональных данных и сведения, которые не нужны для оценки навыков.
  • Текст вакансии для перевода. При использовании функции перевода текст описания вакансии может передаваться сервису MyMemory (MyMemory / MyMemory API) для выполнения запроса перевода. Не отправляйте через эту функцию собственные персональные данные.
  • Технические данные запроса. Хостинг и инфраструктура GitHub Pages могут обрабатывать техническую информацию, необходимую для доставки страниц и обеспечения безопасности. Состав, сроки хранения и место обработки определяются также документами и настройками соответствующего поставщика.

4. Сторонние поставщики и ссылки

Сайт получает сведения о вакансиях из внешних источников и размещает ссылки на их страницы. Переход по внешней ссылке означает взаимодействие пользователя с соответствующим сайтом по его собственным правилам и политике конфиденциальности. Для перевода описания вакансии используется внешний сервис MyMemory. Хостинг Сайта предоставляется GitHub Pages. Оператору необходимо проверять актуальные условия этих поставщиков и фактические сетевые запросы Сайта.

5. Хранение и локализация

Настройки и избранные вакансии, сохраняемые в localStorage, остаются в браузере пользователя до очистки данных сайта или удаления соответствующих записей. Текст резюме не должен сохраняться Сайтом после завершения работы страницы. Сроки хранения технических журналов сторонней инфраструктуры определяются соответствующими поставщиками.

Использование GitHub Pages само по себе не подтверждает выполнение требований локализации.
